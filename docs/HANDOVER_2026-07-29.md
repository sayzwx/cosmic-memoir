## 3. M8 电影级空间记忆

### 场景环境

M8 不再使用大面积信纸、信封和照片 DOM 覆盖层。照片已经成为 Three.js 空间中的 3D 实体。

- 三层温差星场：蓝白主序星、暖金巨星和冷色远星。
- 动态体积宇宙背景：多尺度 fbm 流动云层、青色/紫色/玫瑰色星云和轻微丝状雾化结构。
- 倾斜旋涡星系：四条旋臂、棒状核心、尘带暖色调、星芒辉光和加快约 12% 的自转。
- 近景大气行星：程序化表面、动态云层和 Rayleigh 风格边缘光。
- 暗紫、靛蓝和金红色星云尘埃。
- 暗物质宇宙网：批量 `LineSegments`，随探索进度显形。
- 晶体记忆节点：按质量档位细分几何体，包含内部焦散光、谱色 Fresnel 虹彩、内部辉光和照片边缘辉光。

### 五个晶体记忆节点

### 相机和输入

相机状态：`INTRO`、`OVERVIEW`、`ORBITING`、`FOCUSING`、`FOCUSED`、`RETURNING`、`TABLEAU`。

桌面端：

- 鼠标拖动：环绕视角。
- 滚轮：深潜缩放。
- `W/S` 或 `↑/↓`：前进、后退。
- `A/D` 或 `←/→`：左右环绕。
- `Enter`：聚焦当前可用记忆。
- `Space`：扫描当前记忆。
- `Esc`：返回总览。

移动端：

- 单指拖动：环绕。
- 双指捏合：缩放。
- 空间 UI 扫描按钮：扫描第三张暗网记忆。
- 双指开始时会取消单指拖动，避免误捕获或状态残留。
- 陀螺仪尚未默认开启，避免未经授权请求传感器权限。

## 4. M8 性能预算

典型 High 画质约 13 个 draw calls：动态环境模块、星系、宇宙网和五个晶体节点。

| 档位 | 星场 | 星云尘埃 | 星系粒子 | 宇宙网线段 | DPR |
|---|---:|---:|---:|---:|---:|
| High | 18,000 | 5,000 | 9,000 | 900 | 1.5 |
| Medium | 10,000 | 2,500 | 5,600 | 560 | 1.25 |
| Low | 4,000 | 800 | 2,600 | 260 | 1.0 |
| Mobile cap | 6,000 | 1,200 | 4,200 | 360 | 1.0 |

性能原则：

- 不默认堆到 50,000 个大透明粒子；填充率比顶点数更容易成为瓶颈。
- 移动端按移动预算创建 Buffer，不预分配桌面 High 容量。
- Low 档关闭行星云层和照片色散。
- 高频遥测最多 15Hz，且避免重复写入相同的 `aria-live` 文本。
- 不使用全屏 Ray Marching 或重型多 Pass 后处理。

## 6. 数据契约

M8 由 `data/memories.json` 的显式版本字段识别：

```json
{
  "experience": {
    "id": "M8",
    "variant": "darkMatterCosmicWeb",
    "version": 3,
    "entityOrder": []
  }
}
```

每个晶体节点必须包含：

- `id`
- `role`
- `src`
- `alt`
- `caption`
- `title`
- `body`
- `position[3]`
- `rotation[3]`
- `size[2]`
- `focusOffset[3]`
- `unlockAfter[]`
- `lensingStrength`
- `accent`
- `energyColor`
- `crystalType`
- `discovery.type`

`DataLoader.validateCrystalMemoryV3()` 会在挂载前检查五节点数量、唯一 ID、晶体类型、向量格式、初始解锁状态和最终奇点隐藏规则。

当前照片是本地轻量占位素材：

```text
assets/memories/m8/
```

后续替换真实照片时，保持字段和路径契约即可，不需要修改 Renderer。建议使用 WebP/AVIF、最长边 1600px 以内、单张约 200KB，并清除 EXIF/GPS。

Renderer 输出：

- `sceneTelemetry`

- `spatialMemoryVisited`

- `darkMatterTelemetry`（兼容事件，仅离散状态强制发送）

- `spatialMemoryScanRequested`
- `spatialMemoryReturnOverview`

M8 事件应携带 `memoryId`，避免场景快速切换时旧事件污染当前 UI。

## 8. 共享引擎改动

- `SceneRouter` 增加 mount generation，过期或已销毁的异步场景不会重新挂载。
- 场景初始化失败时释放尚未提交的 Renderer。
- `CosmicMemoirApp` 增加导航事务锁，防止连续点击跳章或越界。
- 当前章节和索引在 `sceneMounted` 前提交，保证进度 UI 使用正确状态。
- `InputAdapter` 增加 pinch `start/move/end` 生命周期。
- 非 M8 场景仍保留 `Space` 前进快捷键。

- 不要提交 `dist` 或 `node_modules`。

- 不要给每颗星、每根丝线创建独立 Mesh。
- 不要默认打开 50,000 个大透明粒子或重型全屏多 Pass。
- M8 环境和照片由模块自行 dispose，不要重复加入基类 `disposables`。
- 保持非 M8 Renderer 的输入签名兼容。
- GitHub Pages 中的隐藏内容只是视觉隐藏，不是真正访问控制。
